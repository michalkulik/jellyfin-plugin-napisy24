Hash lookup (CheckSubAgent)

Hash lookup returns the subtitle matched to the exact release and requires the application credentials below. The default pair belongs to the public Subliminal/Bazarr provider; for a long-lived installation ask napisy24 for your own pair.

Metadata search (webapi)

Automated tasks use hash lookup only by default. Enabling this makes Jellyfin query napisy24 for every new item; keep it off if you care about the site's bandwidth and terms of service.
